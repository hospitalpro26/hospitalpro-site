How publishing works

  1. Open an existing listing or page and update its details.
  2. Review your edits and click Publish to GitHub.
  3. GitHub Pages rebuilds the website. Directory registries also trigger the directory synchronization workflow.
  4. Check the live site after the deployment finishes.
Updating a directory registry does not automatically update every standalone doctor profile, city landing page, or the Slashcure platform. Review those separately.
