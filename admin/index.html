Production architecture

  1. Protect admin accessUse a proper identity provider, such as Cloudflare Access, for administrator sign-in.
  2. Set up a server-side publishing APIOnly a protected backend may write to GitHub using a restricted secret stored on the server.
  3. Migrate current content safelyExtract doctor and hospital entries into JSON, preserve their existing rendered cards and SEO-visible FAQ content.
  4. Review and deployTest first on staging, then publish to main after an explicit go-live approval.
